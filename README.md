# Radia-Examples

This repository contains a set of Jupyter notebooks that show examples
of using the magnet design code Radia. For more information about Radia,
visit the [Radia repository](https://github.com/ochubar/Radia). See also the
original
[ESRF Radia webpage](https://www.esrf.eu/Accelerators/Groups/InsertionDevices/Software/Radia).

## Running on RadiaSoft's Jupyter server

1. Open a terminal on the Jupyter server (File > New > Terminal).
2. Create and enter the directory where the repository will live:
   ```
   cd ~/jupyter
   mkdir -p src/radiasoft
   cd src/radiasoft
   ```
3. Clone this repository:
   ```
   gcl Radia-Examples
   ```
4. In the Jupyter file browser, navigate to `src/radiasoft/Radia-Examples`
   and open any of the `.ipynb` notebooks to run it.
